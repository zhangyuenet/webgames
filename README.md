# webgames
WebGames宪法：
1, 运行在Web上，单机游戏，无服务器，记录保存在浏览器本地，用户可以导出/导入记录，所有数据不上传；
2, 界面无须登录，无须任何用户信息；
3, 所有界面设计均为2D简易线条画风；
4, 游戏是用来消磨时间的，不要太难；
5, 这里的所有游戏都按照Apache开源；

## 塔防小游戏
作为娱乐，我需要一个塔防小游戏。
游戏描述：开局一张地图，有有限的路径，敌人沿着路径不断前进，玩家依赖初始金币构建武器塔防，通过消灭敌人的数量，金币不断上涨，可以添加更多的武器，但敌人也会越来越强大。
当消灭所有敌人后，进入下一局，下一局地图更加复杂，敌人数量更多，敌人等级也越来越高。
武器可以分成：
* 机关枪（点伤害）；
* 单管火炮（一次小范围面伤害）；
* 双管火炮（一次更大范围面伤害）；
* 火箭跑（一次更大范围矩形面伤害）；
* 导弹（一次大圆形面积伤害）；
* 地雷（一次小圆形面积伤害）；
* 陷阱 (一次小圆形面积伤害);
* 墙 （阻碍敌人一段时间）


武器也可以考虑提供多级别。

敌人可以分成：
* 步兵；
* 骑兵（速度较快）；
* 装甲步兵（防御较好）；
* 装甲骑兵；
* 装甲车；
* 坦克；


### 任务1
你帮我设计一个游戏规则：
关卡设计；
防御武器的伤害点数设计；
敌人的防御属性设计；
消灭敌人后的奖励金币设计；
敌人对武器的破坏设计（可以有一些相克的设计属性，例如：墙拦不住坦克，机关枪对坦克无效等）；

### 任务2

希望这些地图既能提供相当地游戏难度，也不至于让用户无法完成；

### 怎么玩

直接用浏览器打开 `index.html`（或 `tower-defense/index.html`）即可，不需要服务器，也不需要安装任何东西。

### 开发

- 纯 HTML / CSS / JavaScript，无构建步骤，无第三方依赖。
- `node tower-defense/tools/sim.js [关卡号]`：无头模拟几种玩法，检查关卡难度。
- `node tower-defense/tools/maps.js`：把关卡数据打印成 ASCII 地图。
- `tower-defense/tools/smoke.html`：用浏览器打开，画一段中局画面，检查渲染。
